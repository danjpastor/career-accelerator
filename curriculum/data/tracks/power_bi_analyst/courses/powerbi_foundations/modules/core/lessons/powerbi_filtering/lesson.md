## Main idea

Filters narrow the data used by a visual or report. Power BI supports filters at several levels: one visual, one page, or the entire report. A **slicer** is a filter control placed directly on the report so the reader can change the view.

Visual interactions determine whether selecting one chart filters, highlights, or leaves another visual unchanged. When a number looks unexpectedly small, check every active filter and slicer before assuming records are missing.

A useful report makes its filter state easy to understand. Clear labels and sensible default selections help the reader know what the numbers represent.

## Example

A recruitment report has a card for total applications and a slicer for Department. Selecting Engineering updates the card and interview chart together. The analyst tests the selection, clears it, and confirms the report returns to the company-wide total before publishing.
