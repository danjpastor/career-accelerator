# Getting Started with Power BI

Power BI Desktop has several work areas because an analyst does different kinds of work at different times.

## Main idea

Power BI Desktop has several work areas because an analyst does different kinds of work at different times.

- **Report view** is where you arrange charts, cards, slicers, and text on report pages.
- **Data view** lets you inspect the rows and columns already loaded into the model.
- **Model view** shows tables and the relationships between them.
- **Power Query Editor** is where you clean and reshape data before it reaches the model.

A safe beginner workflow is: connect to a source, inspect it, transform what needs cleaning, build relationships, create calculations, design visuals, and validate the result. You do not need to memorize every button. You do need to know which work area matches the job you are trying to do.

## Example

A support manager receives a CSV containing ticket date, team, status, and resolution time. The analyst first imports the file and checks the row count in Data view. They use Power Query to set the date and duration types, Model view to inspect relationships, and Report view to build a workload chart. Each view supports a different part of the same workflow.

The graded task uses an orders file instead, so focus on choosing the right view and checking the source before building a report.
