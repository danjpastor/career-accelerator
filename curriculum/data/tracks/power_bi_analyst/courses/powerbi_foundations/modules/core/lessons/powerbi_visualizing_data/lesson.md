# Visualizing Data

A visual should match the question the reader is trying to answer.

## Main idea

A visual should match the question the reader is trying to answer.

- Use a **bar or column chart** to compare categories.
- Use a **line chart** to show change over time.
- Use a **card** for one important number.
- Use a **table or matrix** when the exact row-level values matter.

The fields placed on the axis, legend, and values areas control what the visual means. Power BI may automatically sum a numeric field, but you should always confirm the summarization. A chart can look polished and still answer the wrong question if it counts rows when the manager asked for revenue.

## Example

A facilities analyst wants to compare maintenance cost across buildings. A column chart uses Building on the axis and Sum of Cost as the value. A line chart would imply a time sequence that is not part of the question. Before sharing the chart, the analyst checks the field aggregation and sorts the buildings by cost.
