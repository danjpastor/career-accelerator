# Joining on Multiple Columns

Use a composite key when one column is not sufficient to identify a match.

## What you will learn

- Explain joining on multiple columns.
- Apply joining on multiple columns to an analyst request.

## Main idea

In this step, you will use **composite-key join metrics** inside a complete analyst query. Start by identifying the result grain—what one row should represent—then select only the fields and calculations needed to answer the request. Run the query, inspect the output, and check the answer when the result looks right.

## Key takeaways

- Use a composite key when one column is not sufficient to identify a match.
- Validate the result rather than relying only on valid syntax.
