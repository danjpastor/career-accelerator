# Schemas and Normalization

Balance integrity, duplication, readability, and analytical performance.

## What you will learn

- Explain schemas and normalization.
- Choose appropriate analyst and database decisions involving schemas and normalization.

## Main idea

Analysts use **schemas and normalization** to make database work more accurate, readable, and useful. Read the situation, identify what the result must preserve, and then choose the option that best matches that goal. This check is intentionally short so you can test the idea immediately.

## Key takeaways

- Balance integrity, duplication, readability, and analytical performance.
- Choose designs based on workload, grain, integrity, and maintainability.
