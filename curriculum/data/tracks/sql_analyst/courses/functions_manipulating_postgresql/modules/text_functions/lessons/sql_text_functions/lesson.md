# Parsing and Manipulating Text

Standardize, combine, trim, and extract text values.

## What you will learn

- Explain parsing and manipulating text.
- Apply parsing and manipulating text to an analyst request.

## Main idea

In this step, you will use **text concatenation** inside a complete analyst query. Start by identifying the result grain—what one row should represent—then select only the fields and calculations needed to answer the request. Run the query, inspect the output, and check the answer when the result looks right.

## Key takeaways

- Standardize, combine, trim, and extract text values.
- Validate the result rather than relying only on valid syntax.
