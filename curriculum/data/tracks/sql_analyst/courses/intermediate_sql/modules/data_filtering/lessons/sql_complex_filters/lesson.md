# Complex Filtering

Use range, set, pattern, and missing-value filters together.

## What you will learn

- Explain complex filtering.
- Apply complex filtering to an analyst request.

## Main idea

In this step, you will use **NULL-aware complex filters** inside a complete analyst query. Start by identifying the result grain—what one row should represent—then select only the fields and calculations needed to answer the request. Run the query, inspect the output, and check the answer when the result looks right.

## Key takeaways

- Use range, set, pattern, and missing-value filters together.
- Validate the result rather than relying only on valid syntax.
