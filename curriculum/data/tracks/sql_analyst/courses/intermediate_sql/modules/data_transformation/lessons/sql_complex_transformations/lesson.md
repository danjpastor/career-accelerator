# Complex Transformations

Create calculated fields, percentages, and rounded metrics.

## What you will learn

- Explain complex transformations.
- Apply complex transformations to an analyst request.

## Main idea

In this step, you will use **calculated numeric fields** inside a complete analyst query. Start by identifying the result grain—what one row should represent—then select only the fields and calculations needed to answer the request. Run the query, inspect the output, and check the answer when the result looks right.

## Key takeaways

- Create calculated fields, percentages, and rounded metrics.
- Validate the result rather than relying only on valid syntax.
