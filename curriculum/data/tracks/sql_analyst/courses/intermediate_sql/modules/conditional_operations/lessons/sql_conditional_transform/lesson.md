# Conditional Transformation

Translate business rules into labeled output fields.

## What you will learn

- Explain conditional transformation.
- Apply conditional transformation to an analyst request.

## Main idea

In this step, you will use **conditional transformation** inside a complete analyst query. Start by identifying the result grain—what one row should represent—then select only the fields and calculations needed to answer the request. Run the query, inspect the output, and check the answer when the result looks right.

## Key takeaways

- Translate business rules into labeled output fields.
- Validate the result rather than relying only on valid syntax.
