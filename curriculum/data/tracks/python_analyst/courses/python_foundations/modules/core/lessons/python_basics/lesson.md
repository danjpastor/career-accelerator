## Main idea

Python lets an analyst describe a calculation as a series of repeatable instructions. A **variable** gives a value a name so you can use it again later.

```python
revenue = 900
costs = 650
profit = revenue - costs
```

Python uses `=` to assign a value and `==` to compare two values. Common value types include integers, decimal numbers called floats, text strings, and Boolean values (`True` or `False`). Clear variable names make the business meaning of the code easier to review.

## Example

A scheduling analyst stores `available_hours = 40` and `assigned_hours = 34`, then calculates `unused_hours = available_hours - assigned_hours`. If either input changes, rerunning the code updates the result. The graded exercise uses revenue and costs instead of staffing hours.
