# Text, Dates, Numbers & Duplicates

Clean inconsistent customer names, phone numbers, and date text while preserving the original fields.

## Learn

Reliable cleaning is reversible. Keep the raw value, add a new clean column, and use formulas such as `TRIM`, `PROPER`, `SUBSTITUTE`, or `DATEVALUE` so the transformation is visible.

## Try It

On Customers, add Clean Customer Name in I1. Use a formula that removes extra spaces and applies consistent capitalization, then fill through I13.

## Practice

Add Clean Phone in J1 and Clean Join Date in K1. Use formulas to standardize the phone text and convert the join-date text into usable dates. Fill both columns through row 13.
