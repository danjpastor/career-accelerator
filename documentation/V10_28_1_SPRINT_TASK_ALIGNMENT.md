# Career Accelerator v10.28.1 — Sprint and Task Alignment

## Canonical sprint progress

Current Sprint now counts the named task inventory used by the sprint dialog.
It includes current-week tasks, active carryover, Academy work, DuckDB exercises,
SQL interview problems, assessments, portfolio work, and weekly reviews.

## Catch-up timing

A task is current for its entire scheduled week. It becomes catch-up only when
the application enters a later week and the task remains unfinished.

## Task labels

Dashboard metadata uses specific types: Sheets, SQL, Power BI, Python, Skills
Lab, Portfolio, Review, Career, and Google. Today’s Focus uses a task-type and
week line such as `Spreadsheets • Week 2`. The Google row keeps its weekly
target.

## SQL progress

SQL progress is calculated from the consolidated 16-problem Learning Practice
catalog and its completion records.

## Next Tasks scrolling

The scroll host is resized to its actual content after refresh and density
changes, preventing blank scrolling below the final task.
