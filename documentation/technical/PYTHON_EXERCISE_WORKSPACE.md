# Python Exercise Workspace

Career Accelerator provides 13 Week 8 Python exercises under **Learning → Practice → Python Exercises**.

Each exercise includes:

- A detailed, solution-safe guide.
- A local starter file.
- An integrated Python editor with contextual completion.
- Local Run and Check Exercise controls.
- Printed output and error-line navigation.
- Captured Matplotlib figures.
- Saved notes and a local submission file.
- Durable progress linked to Today’s Focus, Next Tasks, evidence, and prerequisite gates.

Learner code is executed with the application’s local Python interpreter and is not uploaded. Execution is limited to 15 seconds by default so an accidental infinite loop does not freeze the application.

Exercises stay visible but locked until their DataCamp chapter, the Week 7 Knowledge Check, and any earlier Python exercise prerequisites are complete.
