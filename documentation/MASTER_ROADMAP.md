## Scheduling rules

- Completed modules remain completed.
- Only the next incomplete Google module is generated as a task.
- A module scheduled after the active week is hidden, not Catch-Up.
- A module scheduled in an earlier week is Catch-Up and remains first priority.
- Completing a module advances to the next sequential module, but does not pull a future-topic module forward.
- Weekly checks consider every Google module assigned through that week, not merely the one visible task.
- Google tasks can be reduced only by completion, never displaced by DataCamp, practice, labs, or portfolio work.
