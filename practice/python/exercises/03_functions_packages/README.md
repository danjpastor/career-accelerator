# Python Exercise 03: Write functions and use packages

**Week:** 8
**Estimated time:** 40 minutes
**Concepts:** functions, arguments, return values, imports

## Goal

Apply the matching Python chapter in a small analyst workflow. The guide identifies the required result but does not provide finished code.

## Files

- `starter.py` — your working file
- `../../datasets/operations.csv` — shared practice data when the task needs a DataFrame

## Tasks

1. Write a reusable function that calculates net value from a gross value and rate.
2. Add validation so the function handles an invalid negative rate clearly.
3. Import one standard-library package and use it for a small analyst task.

## Validation

- Run the file from top to bottom without errors.
- Confirm that every requested output is produced from variables or data rather than typed answers.
- Check row counts before and after transformations.
- Add two comments explaining a decision and a mistake or check you made.

## Evidence

In the task workspace, record the starter-file path, the outputs you checked, and one short interpretation.

## Common mistakes

- Copying a completed solution instead of writing the code.
- Changing the source data when a new variable or DataFrame should be created.
- Forgetting to inspect data types and row counts.
- Treating code that runs as automatically correct without validating the result.
