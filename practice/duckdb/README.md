# SQL Challenge Practice Library

This library powers the integrated SQL challenge workspace inside Career Accelerator.

Each of the 33 challenges includes:

- one focused SQL task;
- an original Career Accelerator scenario and dataset;
- a schema and first-five-row preview in the lesson panel;
- three progressive hints;
- specific column, row-count, value, ordering, and required-technique checks;
- a locally saved SQL submission.

Open **Learning → Practice → SQL Challenges** in Career Accelerator. The existing DuckDB exercise workspace provides the editor, Run Task, Check Task, Hint, Check Exercise, and Submit Exercise controls. No separate setup or external editor is required.

The source link shown in each lesson identifies the public challenge pattern that inspired the exercise structure. Career Accelerator uses original wording, records, expected output, hints, and solutions.
