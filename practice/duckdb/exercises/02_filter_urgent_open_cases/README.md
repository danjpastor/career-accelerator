# Filter Urgent Open Cases

> **Challenge structure source:** [SQL Practice — Filter records by one condition](https://www.sql-practice.com/)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

The support director is preparing a same-day escalation list.

## Your task

Return the open support cases whose priority is `Critical`.

## Result requirements

- Return `case_id`, `subject`, and `assigned_team`.
- Sort by `case_id` from lowest to highest.

## Skill focus

**WHERE filters**

Use more than one condition to keep only the records a manager requested.
