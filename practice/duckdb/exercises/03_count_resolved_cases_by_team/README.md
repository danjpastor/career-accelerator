# Count Resolved Cases by Team

> **Challenge structure source:** [SQL Practice — Count records by city](https://www.sql-practice.com/)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

The operations lead wants a quick view of which teams closed the most cases.

## Your task

Count resolved cases for each assigned team.

## Result requirements

- Return `assigned_team` and `resolved_case_count`.
- Show only teams with at least one resolved case.
- Sort by `resolved_case_count` descending, then `assigned_team` ascending.

## Skill focus

**Aggregate functions and GROUP BY**

Count matching records at the requested business grain.
