# Search Support Subjects Without Case Sensitivity

> **Challenge structure source:** [PostgreSQL Exercises — Perform a case-insensitive search](https://pgexercises.com/questions/string/case.html)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

Quality assurance is reviewing any support case whose subject mentions a charge.

## Your task

Return support cases whose subject contains the word `charge`, regardless of letter case.

## Result requirements

- Return `case_id` and `subject`.
- Sort by `case_id`.

## Skill focus

**Case-insensitive search**

Find text regardless of capitalization.
