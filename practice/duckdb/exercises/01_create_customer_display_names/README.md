# Create Customer Display Names

> **Challenge structure source:** [SQL Practice — Combine first and last names into one full-name column](https://www.sql-practice.com/)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

Northstar support agents need one clean customer label for a new case-assignment screen.

## Your task

Return each customer ID with the customer’s first and last name combined as `customer_name`.

## Result requirements

- Return `customer_id` and `customer_name` in that order.
- Sort by `customer_id` from lowest to highest.

## Skill focus

**SELECT expressions and aliases**

Build one readable display field from two source columns and name it clearly.
