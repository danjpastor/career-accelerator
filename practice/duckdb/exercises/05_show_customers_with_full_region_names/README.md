# Show Customers with Full Region Names

> **Challenge structure source:** [SQL Practice — Join patients to full province names](https://www.sql-practice.com/)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

The reporting team wants readable region names instead of internal region codes.

## Your task

Return every customer with the full name of the customer’s region.

## Result requirements

- Return `customer_id`, `customer_name`, and `region_name`.
- Sort by `customer_id`.

## Skill focus

**INNER JOIN**

Connect two tables through a matching key and select fields from both.
