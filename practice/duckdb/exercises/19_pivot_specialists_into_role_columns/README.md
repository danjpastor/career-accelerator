# Pivot Specialists into Role Columns

> **Challenge structure source:** [HackerRank — Occupations](https://www.hackerrank.com/challenges/occupations/problem)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

A staffing brief needs one compact roster with a separate column for each specialty.

## Your task

Pivot specialist names into `analyst`, `designer`, `engineer`, and `manager` columns.

## Result requirements

- Alphabetize names within each specialty before assigning row numbers.
- Return the four specialty columns in the listed order.
- Sort by the generated row number.

## Skill focus

**ROW_NUMBER and conditional aggregation**

Reshape category rows into aligned columns without losing names.
