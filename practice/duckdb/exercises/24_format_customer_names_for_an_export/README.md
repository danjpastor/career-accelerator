# Format Customer Names for an Export

> **Challenge structure source:** [SQL Practice — Format last names in uppercase and first names in lowercase](https://www.sql-practice.com/)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

A legacy partner requires names in a specific `LAST, first` format.

## Your task

Format every customer name with the last name uppercase and the first name lowercase.

## Result requirements

- Return `customer_id` and `export_name`.
- The format must be `LAST, first`.
- Sort by `customer_id`.

## Skill focus

**UPPER, LOWER, and concatenation**

Apply text casing rules and build a formatted export value.
