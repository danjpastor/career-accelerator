# Find the Lowest-Revenue Restaurants

> **Challenge structure source:** [StrataScratch — Lowest Revenue Generated Restaurants](https://platform.stratascratch.com/coding-question?id=2036)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

A delivery marketplace is selecting two restaurants for a revenue-support pilot.

## Your task

Return the two restaurants with the lowest total platform revenue.

## Result requirements

- Platform revenue equals `subtotal + service_fee`.
- Return `restaurant_name` and `total_revenue`.
- Round `total_revenue` to two decimals.
- Sort by `total_revenue`, then `restaurant_name`.

## Skill focus

**Revenue aggregation and ranking**

Calculate revenue by entity and select the bottom-performing group.
