# Classify Orders by Value

> **Challenge structure source:** [HackerRank — Type of Triangle](https://www.hackerrank.com/challenges/what-type-of-triangle/problem)  
> Career Accelerator rebuilt this exercise with original wording, scenario, schema, records, expected output, hints, and solution.

## Scenario

The sales team wants a simple size label for completed orders.

## Your task

Classify each completed order as `Small`, `Standard`, or `Large` based on its total amount.

## Result requirements

- Use `Small` below 100, `Standard` from 100 through 299.99, and `Large` at 300 or more.
- Return `order_id`, `total_amount`, and `order_size`.
- Sort by `order_id`.

## Skill focus

**CASE expressions**

Turn numeric values into clear business categories.
