# Complete exploratory analysis

**Project:** VFX Production Intelligence Dashboard  
**Stage:** Python  
**Estimated focused time:** about 150 minutes

## What you're doing

Explore the cleaned data for useful patterns, segments, trends, and unusual records tied to the project questions.

Use the Studio or Notebook tab in this milestone when one is available. Open an external tool only when the work genuinely belongs there, such as Power BI or a spreadsheet editor.

## Why it matters

Exploration helps you understand the data before deciding which patterns are strong enough to report.

## Before you start

- Use the cleaned analytical data.
- Keep the approved business questions nearby.

## Steps

1. Open the EDA Notebook.
2. Explore coverage, distributions, categories, and important segments.
3. Look for time patterns and relationships tied to the project questions.
4. Investigate unusual records without assuming they are errors.
5. Create only visuals that help explain a useful pattern.
6. Write candidate findings and separate them from open questions.
