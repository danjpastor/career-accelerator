# Data Career Accelerator

Version 10.33.0 introduces the new shared Accelerator Academy learning system.

Spreadsheet, SQL, Power BI, and Python lessons now follow one beginner-friendly sequence:

**Learn → Check → Example → Try It → Practice → Apply It → Recap**

Lessons explain unfamiliar terms in plain language, show an original example with different data, provide guided practice, then ask the learner to solve a less-guided workplace task. Exact formulas, queries, and code for graded activities appear only through **View Solution**.

The replacement curriculum contains 63 lessons and 448 short learning activities. Existing Academy progress is reset because these are new lessons. Portfolio projects, applications, settings, learner databases, and other non-Academy work are preserved.
