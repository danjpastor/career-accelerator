### Practice workbook
- **Workbook:** Northstar Operations Practice Workbook.xlsx
- **Sheet:** `Orders`
- **Rows:** A1:J37
- **Columns:** `Order ID`, `Order Date`, `Customer ID`, `Region`, `Sales Rep`, `Product ID`, `Units`, `Unit Price`, `Discount`, `Status`

**Column guide**
- **Order ID:** Unique text identifier for one customer order.
- **Order Date:** Date the customer order was created.
- **Customer ID:** Identifier that connects an order to the Customers sheet.
- **Region:** Sales territory assigned to the order or customer.
- **Sales Rep:** Employee responsible for the order.
- **Product ID:** Identifier that connects an order to the Products sheet.
- **Units:** Number of product units ordered.
- **Unit Price:** Selling price for one unit, stored in U.S. dollars.
- **Discount:** Order discount stored as a decimal percentage.
- **Status:** Current order status from the approved lookup list.

**Example values:** `Order ID: NS-1001`, `Order Date: 01/05/2026`, `Customer ID: C001`, `Region: West`, `Sales Rep: Maya Chen`

**Starting state:** The Orders data has one header row and 36 order records, but no saved table or filter.

**Finished result:** The full Orders range is filterable and still contains all 36 order records.
